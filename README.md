# PriceLens – Price Comparison & Alert System

## Overview

PriceLens is a web-based application that helps users track product prices across multiple e-commerce platforms and receive notifications when prices drop. The system collects and stores historical price data, enabling users to compare prices, analyze trends, and make informed purchasing decisions.

---

## Features

- Track product prices from multiple e-commerce websites
- Compare prices across different platforms
- View historical price trends
- Automated price drop notifications
- Interactive dashboard for price visualization
- User-friendly web interface

---

## Tech Stack

**Python, Flask, SQLite, Pandas, Altair, HTML, CSS, JavaScript**

---

## Workflow

1. Enter the product URL from a supported e-commerce website.
2. The system extracts product details and current price using web scraping.
3. Product information is stored in a SQLite database.
4. Price history is updated periodically.
5. Users can visualize price trends through interactive charts.
6. Email notifications are sent automatically when the product price drops.

---

- Developed web scrapers to monitor products across **4+ e-commerce platforms**.
- Collected and maintained a historical dataset containing **10,000+ price records**.
- Built an interactive dashboard using **Altair** for trend analysis.
